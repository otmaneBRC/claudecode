# Velvet ribbon dog collar (Blender model)

`velvet_ribbon_dog_collar.blend` is a real-world-scale model (scene units: metres, displayed in mm) of an
adjustable velvet ribbon collar with a detachable bow tie. It is generated by a script, so every dimension
can be changed and the file rebuilt.

## What is in the file

| Collection | Object | What it is |
|---|---|---|
| `Collar_Strap` | `Webbing_25mm` | One continuous 1 in (2.5 cm) webbing core, 26 in (66 cm) cut length |
| | `Velvet_Ribbon_22mm` | 7/8 in (2.2 cm) velvet ribbon sewn to the decorative face, webbing border visible both sides |
| | `Stitching` | Edge-stitch round the ribbon, box-X on the slider tail, 3 rows + box-X at the fixed end |
| `Collar_Hardware` | `Slider_TriGlide` | Three-bar slider |
| | `Buckle_Female`, `Buckle_Male` | Metal side-release buckle (spring arms latch into the side windows), engraved face |
| | `D_Ring_Welded` | D-ring trapped between the stitch rows |
| `Bow_Tie` | `Bow_Body`, `Bow_Knot_Band`, `Bow_Elastic_Loop` | Pleated velvet bow; the elastic loop on the back slides over the collar. Parented to the `Bow_Tie` empty |
| `Studio` | floor, 3 lights, 5 cameras | `Cam_Hero`, `Cam_Top`, `Cam_Buckle`, `Cam_Slider`, `Cam_Inside` |

## Strap path (the order to show in a tutorial)

1. Cut end 1 goes round the slider's **centre bar**; the tail folds back and is sewn with a square-with-X.
2. The strap runs to the **male buckle half**, round its bar, and comes back on the outside.
3. It passes under / over / under the three slider bars, decorative face out, no twist.
4. It runs round the neck, over the **D-ring** bar, then round the **female buckle half** bar.
5. The tail returns on the inside under the D-ring bar: one row between buckle and D-ring, two rows behind
   the D-ring, and a box-X at the tail end. The cut end is sandwiched on the inside.

`renders/threading_section.png` shows this path in cross-section.

## Numbers (starting points — confirm with a test collar)

- Cut length 26 in (66 cm); modelled at a 16.1 in (41 cm) neck setting, slider 83 mm from the male buckle bar.
- Strap thickness 2.2 mm (1.4 mm webbing + 0.8 mm velvet); bars 3 mm; slider slots 7.5 mm.
- Scene custom properties store `cut_length_mm`, `neck_circumference_mm`, `slider_to_male_bar_mm`.

## Video tutorial

`tutorial/velvet_collar_tutorial.mp4` shows the build in 13 captioned steps, assembled flat on a table.

```bash
python3 make_tutorial.py --check              # every animated frame: strap vs strap / hardware / table
python3 make_tutorial.py --render --final     # frames into tutorial/frames/ (resumes if interrupted)
python3 assemble_video.py                     # captions + mp4 (edit the caption text here)
```

In every frame the strap is the full 26 in long and touches nothing it should not: threading is shown by
sliding the strap along its route (slider loop) or by moving a buckle bar along the strap so the strap
rolls round it. Hands, the sewing machine and the bow's own construction are not shown.

## Rebuild / check

```bash
pip install bpy            # or use: blender -b -P build_collar.py -- --render
python3 build_collar.py --render --samples 128
python3 verify_section.py renders/threading_section.png   # threading: strap vs strap / bars (needs shapely, matplotlib)
python3 check_overlaps.py                                  # 3D: no part intersects another or itself
```

Edit `P` in `collar_geometry.py` (sizes, tail lengths, neck setting) or the constants at the top of
`build_collar.py` (colours, `ENGRAVING`). The slider position is solved from the cut length.

## Modelling simplifications

- The buckle halves use one strap bar each (the strap is sewn, not ladder-threaded).
- Ribbon ends are cut 2 mm short of the webbing ends and stitched across (not folded under).
- The bow is shown detached, lying on the floor with its elastic loop relaxed.
- Velvet pile is a shader (sheen + fine bump), not hair geometry.
